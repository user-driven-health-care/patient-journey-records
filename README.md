# Patient Journey Records (PaJR) Dataset

This collection of PaJRs is part of User Driven Health Care (UDHC), an initiative led by Dr Rakesh Biswas, professor of Medicine at the Kamineni Institute of Medical sciences near Hyderabad, India. His interests include clinical problem solving applied to patient centered health care and health education. Below is a compiled list of anonymized, patient consented PaJRs. 

If you have a PaJR to contribute to this list, please submit a PR (just edit this page and submit as a pull request for this to be added to this list). 

- [2023 Jun - 32Y Male with fever and dysphagia since 1 week](https://vaishnavimaguluri.blogspot.com/2023/07/general-medicine-case-report-osce.html)
- [2022 Feb - 70Y Female drowsy with h/o fall and vomiting](https://vaishnavimaguluri.blogspot.com/2022/02/this-is-online-e-loo-discuss-our.html)

A lot more can be found here

## Project Milestones

1. Blog → Text/Image PaJR dataset - Convert 5000+ blogspot pages into text docs and images for easy machine readability
2. Whatsapp → Text/Image PaJR dataset - Bot to extract anonymized data from Whatsapp group/chat and turn it into machine readable PaJR
3. Text/Image PaJR dataset → Machine readable medical KG PaJR dataset - Join with Diseasonomics / SNOMED / LOINC
4. Medical KG PaJR dataset → TemporAI compatible time series dataset - Work with Cambridge to do time series analysis on the Medical KG PaJR dataset using TemporAI from the VarDerSchaar lab at Cambridge.
